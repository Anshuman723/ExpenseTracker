# 💰 Expense Tracker

A simple and user-friendly Expense Tracker web application that helps users manage their daily income and expenses efficiently.

---

## 🚀 Features

- ➕ Add income and expenses  
- ➖ Delete transactions  
- 📊 View balance, income, and expenses summary  
- 💾 Data stored in browser using Local Storage  
- 📱 Responsive design for all devices  

---

## 🛠️ Technologies Used

- HTML – Structure of the application  
- CSS – Styling and layout  
- JavaScript – Functionality and logic

## ⚙️ How to Run the Project

1. Download or clone the repository  
   ```
   git clone https://github.com/your-username/expense-tracker.git
   ```
2. Open the project folder  
3. Double-click on `index.html` or open it in your browser  

---

## 🧠 How It Works

- Enter a description and amount  
- Positive amount = Income  
- Negative amount = Expense  
- The app automatically updates:
  - Total Balance  
  - Total Income  
  - Total Expenses
